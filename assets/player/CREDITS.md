# Human footballer asset package

Model ID: `tribun-makehuman-footballer-v1`.

The anatomical body is the MakeHuman Community hm08 base mesh at commit `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`. The OBJ header explicitly releases this asset under CC0 in September 2020 and names Data Collection AB, Joel Palmius and Jonas Hauquier. The matching default skeleton and weights explicitly declare CC0. Source program code is not copied. `SOURCE-LICENSE.md` explains the distinction between AGPL program code and CC0 core assets; `LICENSE-CC0.txt` contains the upstream asset licence.

Original source files are retained deterministically compressed under `source/`, with exact download URLs and SHA-256 values in `source/provenance.json`. The body source SHA-256 is `8e761e6624b8f54536409135d1636da63b32486a90d4897f84e121d144f6fb4c`.

The project-authored derivative adds a football kit material layout, clothing offsets, football boots, eyes, brows, a 19-bone collapsed skin, a rig-compatible bind pose and two generated neutral detail textures. The canonical athletic bind is 1.88 m tall, with 0.44 m shoulder-joint span, 0.26 m hip-joint span, 0.475/0.431 m leg segments and 0.315/0.290 m arm segments. The head bone is 0.25 m, hands are 0.17 m and authored boots are 0.29 m long. These are authored adult proportions, not a measured population average. Source skin weights are retained verbatim in the pinned upstream archive and normalized/collapsed by anatomical ancestry for bind geometry. Runtime weights are an authored derivative: six simultaneous Jacobi smoothing rounds, 0.5 self plus 0.5 uniform neighbor mean on original body quad edges before UV/material splitting, then largest-four normalization. Painting is restricted to shoulder (0.18 m), elbow (0.12 m) and knee (0.15 m) patches whose adjacent bone weights sum above 0.35. All source hand influences and vertices within 0.13 m of either wrist are protected. Bind positions, normals, material assignments and UVs use the original collapsed weights and do not change during this painting step. Limb proportions are corrected along the original source axes with positive scale before a separate normalized dual-quaternion blend rotates the source into the canonical bind. No affine rotation blend is used to bake the bind. Head width and depth are reduced continuously and the front chest receives a continuous neutral athletic envelope. Runtime rigid dual-quaternion skinning and local weight painting reduce collapse in measured joint patches; they are not universal corrective anatomy and extreme-pose surface intersections can remain. These added asset components are released under CC0-1.0. They are original mathematical texture maps, not photos or scanned skin. No real footballer likeness, sponsor logo or external portrait is used.

`footballer.glb` is a standard glTF 2.0 binary containing the mesh, skin, 19 joints, embedded textures and materials. It has no motion-capture or baked animation clips. `player-model-data.js` carries the same derived geometry for the existing WebGL renderer. It currently provides one drawable quality level; no multi-LOD performance claim is made.

Rebuild offline with `python3 tools/build-player-assets.py --from-package --output /tmp/tribun-player-rebuild`. The packaged originals are unpacked into a temporary input directory and all five pinned file hashes and official provenance URLs are checked before generation. The reviewed rig reference SHA-256 is `c66a9fcdb884fdf3cda3f7e92fc4c9ebe1dbbec32fa1bfdb0a8c020099125480`. A changed rig must be reviewed before updating that pin. The original checked download directory can also be supplied with `--source-dir`. The builder requires Python, numpy, Pillow and Node for the reviewed canonical rig reference. Runtime play needs no builder dependencies.
