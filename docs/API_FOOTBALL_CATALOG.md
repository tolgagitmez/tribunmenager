## Versioned ability model

The default adapter remains neutral (80, position-default attributes). For offline experimentation, call `toGameRoster(snapshot, {ratingMode:'synthetic-varied'})`. This is a synthetic game-design mode, not scouting: stable provider UID plus broad position determines a bounded blend of existing archetype templates with correlated physical, technical and mental variation. Overall is a weighted deviation from the broad-role baseline, centered at 80; weights emphasize position-relevant skills. Player name, age, club and roster order do not affect ratings. Missing precise role and dominant foot remain unknown. `ratingProvenance` explicitly marks every generated attribute synthetic, no measured confidence, model version 1. Do not advertise these as accurate real-world player ratings. This metadata is separate from the existing normalize() contract. The game consumes the computed attributes through the same player model. Existing league saves are unchanged. Accurate real-world calibration requires authorized, comparable statistics or scouting data; no such data is used here. Offline tests cover 1200 generated profiles, stability, positional weights and actual Match integration. No real API call is performed by this test workflow.
