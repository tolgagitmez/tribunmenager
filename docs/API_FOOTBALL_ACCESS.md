# API-Football access probe

This branch verifies account status, one current squad (team 33), and Premier League season 2026 with at most three HTTP requests per invocation, no retries, and quota checks. The API key is supplied only by the GitHub Actions repository secret API_FOOTBALL_KEY. No credentials, names, images, raw API responses, or artifacts are emitted. It does not import or publish real rosters, use fictional skill values as facts, change the game engine, or schedule daily synchronization. Before commercial use or persistent caching, confirm the provider's data rights and relevant third-party rights. A successful current squad response does not establish availability of the current season or a license to distribute it. Official docs: https://www.api-football.com/documentation-v3 and https://www.api-football.com/terms.
