# Stage 103 — combined AI worker capacity

Runs 1, 2, 3 concurrent 300-second matches using the same frozen Stage 102 runtime and the actual integrated candidate, with distinct job directories and a start barrier. Existing queue transaction/recovery regressions run first (not a real process-crash integration test). Each result must validate combined policy probes, game statistics, exact duration and resource data. Gate requires 240 seconds common observed overlap, individual wall time within one second and trace gaps <=1s, and >=90% one-second aligned native PSS sample coverage. Optional operator-supplied PSS budget; default CI has no explicit memory cap. The aligned sum is an approximation within 0.75s and excludes Python, OS and network memory. Preserve trace hashes and runtime/source evidence, checkpoint after each group, stop before larger groups if a gate fails. No change to official server worker count (1–3), lease transactions, league results or production flags. This measures one CI host, not a hosting capacity recommendation, concurrent user capacity or a guarantee.
