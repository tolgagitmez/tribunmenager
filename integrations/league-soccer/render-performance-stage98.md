# Stage 98 — replay graphics and mobile performance

Optional replay optimization. Stop redundant drawing and Rig.sample calls when a paused frame has settled; retain cached pose, redraw for camera, canvas resize, quality changes, model loading and seek. Active playback still draws on requestAnimationFrame. Hidden presentation draws are skipped, while the existing 300-second broadcast wall clock continues. Camera smoothing uses exponential interpolation and snaps on seek. Cap render pixels by viewport and quality (mobile 450k / 800k / 1.3m; desktop 1m / 1.8m / 3m). Existing hardware-supported instancing is enabled only in performance mode; normal fallback retained. Native special contact poses are not deliberately reduced by distant transition shortcuts in this option. UI reports rolling CPU frame submission duration, draw calls, triangle counts, resolution and skipped frames, not GPU time or measured device FPS. Browser tests verify paused caching, 390px viewport budget and preserved score, not actual iPhone performance. Existing models, lighting, shadows and production game remain unchanged. No promise of 60 FPS.
