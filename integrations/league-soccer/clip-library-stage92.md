# Stage 92 — existing clip library replay pilot

Reuses the project's 1.5 MB Blender-exported footballer GLB, whose four clips (idle, run, shoot, dive-right) were originally baked from our procedural rig, not captured human motion. MakeHuman bundled source assets are CC0; see assets/interchange/SOURCE-LICENSE.md and manifest.json. No new third-party motion asset was imported: upstream repository Apache-2.0 is not an independently verified provenance chain for individual original animation files. Load once on opt-in, sample local shoulder-to-hand vectors at approximately 30Hz into a shared immutable library. Run phase follows existing procedural gait, idle uses a static midpoint, shot has a bounded pre/post upper-arm contribution, no imported target within 60ms of actual shot contact. Keeper/dive clip is loaded/validated but deliberately not used yet, as exact hand contact must remain authoritative. No imported legs, root motion, contact target changes, ball changes or new AI. Each arm target passes existing anatomical IK, including player stature. Browser test loads the actual GLB and verifies active clip sampling; synthetic unit tests check fallback and unchanged legs/ball. Main game unchanged. Real motion capture, additional clip rights verification, visual quality and mobile performance remain outstanding.
